# ☁️ MeridiSkies

**Sky & weather explorer in your browser — play with the air, clouds and light.**
ブラウザで動く、空と天気の図鑑・実験。空気・雲・光をさわって学べます。

▶ **Open MeridiSkies → https://meridibrand.com/skies/**

> No Ads. No Subscriptions. Just Tools.

---

## Tabs / できること
| Tab | What you can do |
|---|---|
| ⬆ **Climb the Sky** / 空を昇る | Scroll up from the ground to 16 km — temperature, pressure, clouds by height, freezing level, airliners |
| 🌧 **Rain & Snow** / 雨と雪 | Change temperature, rain and wind — rain, sleet, snow, fog and whiteouts under a moving cloud deck |
| ⚡ **Lightning** / 雷 | Branching bolts, return strokes, in-cloud flashes — guess the distance from the thunder |
| 🌌 **Aurora** / オーロラ | Curtains, coronas and arcs from 8 places, with the colors you see by eye and on camera |
| 🏔 **Foehn** / フェーン | Air rising and falling over a mountain — the foehn wall, lenticular clouds and the temperature graph |
| ⛈ **Cloudburst** / 夕立 | Cumulus → towering cumulus → cumulonimbus with an anvil, rain shafts and hail |
| 🌙 **Night Cooling** / 放射冷却 | Why clear, calm nights get cold — dew, frost, radiation fog, valley seas of cloud |
| 🌈 **Sky Colors** / 空の色 | Sunsets, afterglow, blue hour, rainbows, halos & arcs, green flash and more |
| 🗾 **Japan & Regions** / 日本と地域 | Monthly weather maps, fronts and lows, kogarashi, shear lines |
| 🌍 **Earth** / 地球 | Globe, three circulation cells, jet streams, El Niño / La Niña |
| 📖 **Guide** / 図鑑 | 79 entries, a ten-cloud-types chart by height, world seasonal words |

## Features / 特長
- ☁️ Clouds and aurora drawn point by point with WebGL (lighter drawing on older devices)
  雲とオーロラは WebGL で点ごとに計算（古い端末では軽い描き方に）
- 🪶 Lite mode for phones and older devices / スマホや古い端末向けの軽量モード
- 🌐 日本語 / English
- 📦 Single HTML file — no install, no account / インストールも登録もいりません

## Notes / ご注意
- This is for learning, not a weather forecast. Figures are rough guides based on JMA and similar sources.
  学ぶための再現で、天気予報ではありません。数字は気象庁などの資料をもとにした目安です。
- Found something wrong? Let us know in [Discussions](https://github.com/meridi-support/meridi-square/discussions).
  おかしな所があれば、Discussions で教えてください。

## Privacy / プライバシー

  GoatCounter によるページビューの数（匿名）だけを計測しています。
